# 국외 전투기 항공전자 주간동향 도구 (MVP)

PRD(`PRD_국외전투기_항공전자_주간동향_도구.md`)를 바탕으로 만든 로컬 웹앱입니다.
작성자 PC에서 실행하고, 브라우저로 사용합니다.

## 1. 처음 한 번만: 준비

1. **Python 설치** (3.10 이상)
   - https://www.python.org/downloads/ 에서 Windows 설치 파일을 받습니다.
   - 설치 첫 화면에서 **"Add python.exe to PATH"를 반드시 체크**합니다.
2. **이 폴더(`avionics_weekly`)를 원하는 곳에 둡니다.** 폴더 경로에 한글이 있어도 됩니다.

## 2. 실행

| 하고 싶은 일 | 방법 |
|---|---|
| 내 PC에서만 쓰기 | **`run.bat` 더블클릭** → 브라우저에 `http://127.0.0.1:5000/` 이 열림 |
| 다른 PC·안드로이드 폰에서 보고서 보기 | **`run_share.bat` 더블클릭** (아래 4번 참고) |
| 지금 바로 지난주 소식 수집 | **`collect_now.bat` 더블클릭** (API 키 필요) |
| 끄기 | 검은 창에서 `Ctrl + C` 또는 창 닫기 |

- 실행할 때 필요한 패키지(Flask, lxml, anthropic)를 자동으로 확인·설치합니다(처음 1~2분, 인터넷 필요).
- 명령어로 실행하려면: `python -m pip install -r requirements.txt` 후 `python app.py`

## 3. 소식 수집 (API 키 없이)

수집은 **Claude 데스크톱 앱의 예약 작업 '항공전자 주간 수집'**이 합니다. API 키와 별도 요금이 필요 없습니다.

| 언제 | 방법 |
|---|---|
| 매주 자동 | 월요일 06:45경 Claude 앱이 지난주 소식을 검색·검증해 저장합니다. **PC와 Claude 앱이 켜져 있어야 합니다.** 꺼져 있었다면 다음에 Claude 앱을 켤 때 실행됩니다 |
| 필요할 때 (수동) | ① 앱 ① 주간 소식함에서 주차를 고르고 **'이 주차 수집 요청'** → ② Claude 앱 사이드바 **예약 작업 → '항공전자 주간 수집' → 지금 실행** |
| 대화로 | Claude 앱 대화창에서 "2026-W40 소식 수집해줘"라고 요청해도 됩니다(`COLLECT_GUIDE.md` 절차를 따름) |

- 수집 절차와 기준은 `COLLECT_GUIDE.md`에 있습니다. 이 파일을 고치면 다음 수집부터 반영됩니다.
- 저장할 때 기간 밖, 이미 저장된 소식, 링크가 열리지 않는 건은 자동으로 제외합니다(`claude_collect.py`).
- 예약 작업 시각·내용은 Claude 앱 사이드바의 예약 작업에서 바꾸거나 끌 수 있습니다.

## 3-1. (선택) API 키로 앱 안에서 AI 기능 쓰기

키가 없어도 수집(위 방법), 직접 추가, 검토, 보고서·소요제기 초안, hwpx 다운로드가 모두 됩니다.
키를 넣으면 앱 안의 'AI 분석'(직접 추가할 때), 'AI 초안'(소요제기) 버튼과 앱 자체 자동 수집을 쓸 수 있습니다.

1. Claude 개발자 콘솔(https://console.anthropic.com)에서 API 키를 발급합니다. (API 사용료가 별도로 듭니다.)
2. 처음 실행하면 생기는 `config.json` 파일을 메모장으로 열어 키를 넣습니다.
   ```json
   "anthropic_api_key": "sk-ant-...여기에 키..."
   ```
3. 앱을 다시 실행합니다. ④ 기준 정보 화면 아래 '설정 상태'에 "API 키: 설정됨 ✅"이 보이면 됩니다.

| config.json 항목 | 의미 |
|---|---|
| `model` | 사용할 Claude 모델 ID(기본 `claude-opus-5-5`). 비용을 줄이려면 `claude-sonnet-5-5` |
| `web_search_tool` | 웹 검색 도구 버전 문자열 |
| `max_searches` | 1회 수집 때 최대 검색 횟수 |
| `auto_collect`, `collect_weekday`, `collect_time` | 자동 수집 켜기, 요일(0=월), 시각 |
| `port` | 웹 주소 포트(기본 5000) |

**자동 수집은 앱이 켜져 있을 때 동작합니다.** 매주 월요일 06:45가 지나면 지난주(월~일) 소식을 한 번 수집합니다.
월요일 아침에 앱이 꺼져 있었다면, 그 주에 앱을 켜는 즉시 수집합니다. 수집이 실패하면 1시간 뒤 다시 시도합니다.
PC를 켜 두지 않는다면 Windows **작업 스케줄러**에 `collect_now.bat`을 월요일 06:45로 등록해도 됩니다.

> 키는 다른 사람과 공유하지 마세요. `config.json`은 보고서와 함께 보내지 않습니다.

## 4. 보기 전용 공유 (과장님·담당자 9명)

1. 보고서를 **확정** 또는 **확정 + 공유**로 저장합니다.
2. **`run_share.bat`** 으로 앱을 실행합니다. 처음에 Windows 방화벽 허용 창이 뜨면 '허용'을 누릅니다.
3. ② 주간 보고서 화면 오른쪽 '보기 전용 링크'의 **둘째 줄 주소**(`http://내PC-IP:5000/view/...`)를 전달합니다.
   - 같은 네트워크에 있는 PC·안드로이드 폰에서 열 수 있습니다.
   - 이 링크로는 **읽기와 hwpx 다운로드만** 되고, 편집 화면은 이 PC(127.0.0.1)에서만 열립니다.
4. 같은 네트워크가 아니거나 보안 정책으로 접속이 막히면, **hwpx 파일을 메일·메신저로 전달**하세요.

## 4-1. 웹 배포본 (Vercel, 보기 전용)

GitHub `main`에 푸시하면 Vercel이 자동으로 배포합니다. 웹 배포본은 **열람 전용**입니다.

- 편집 기능(소식 수정·추가·삭제, 보고서 편집, 수집, 소요제기, 기준 정보)은 없습니다(404). 편집은 항상 작성자 PC의 `run.bat`에서 합니다.
- 화면 구성은 작성자 화면과 같지만(① 주간 소식함, ② 주간 보고서) 읽기만 됩니다.
- 웹에는 **확정·공유한 보고서가 있는 주차의 보고서와 그 주차 소식 전체**가 올라갑니다. 기준 정보, 소요제기 초안, 작성자 메모, 보고서 미확정 주차는 올라가지 않습니다.
- 웹 주소를 아는 사람은 누구나 공개된 보고서를 볼 수 있습니다. 보안 규정상 제한이 필요하면 Vercel의 Deployment Protection으로 접근을 막으세요.

웹에 보고서를 올리는 순서:
1. ② 주간 보고서에서 **확정** 또는 **확정 + 공유**로 저장
2. `avionics_weekly` 폴더에서 `.venv\Scripts\python.exe publish.py` 실행 → `published/snapshot.json` 갱신
3. GitHub에 커밋·푸시 → 1~2분 뒤 웹에 반영 (Claude에게 "보고서 웹에 올려줘"라고 해도 됩니다)

## 5. 매주 사용 흐름

1. **① 주간 소식함**: 주차를 고르면 지난주 소식이 분야별 카드로 나옵니다.
   - 카드를 눌러 요약·출처·기종별 적용 가능성(상·중·하)을 검토하고 고칩니다.
   - 유료 기사는 '직접 추가'로 넣습니다(AI 분석 또는 직접 입력).
   - ⚠️ 표시는 출처 링크가 자동 확인되지 않은 것입니다. 직접 열어 확인하세요.
2. 보고서에 넣을 소식 2~3건을 체크 → **'선택한 소식으로 주간 보고서 만들기'**
3. **② 주간 보고서**: 본문을 고치고 확정 → hwpx 다운로드·링크 공유
   (`# ` 는 큰 제목, `## ` 는 소제목)
4. **③ 소요제기 초안**: 소식 1건 선택 → 기본 초안 또는 AI 초안 → 수정 → hwpx 다운로드
   (지금은 **임시 목차** 7개 항목. 정식 양식을 받으면 교체 예정)
5. **④ 기준 정보**: 우리 공군 기종 목록과 기종별·분야별 현재 수준(개략)을 관리합니다.
   현재 수준을 모르면 '공개 자료 추정값'을 고르고 근거 링크를 적습니다.

## 6. 보안·운영 원칙

- **공개 자료만** 다룹니다. 우리 기종 정보는 "레이더 성능개량 필요"처럼 **개략적인 표현만** 입력합니다.
- 공개 정보라도 모아 놓으면 민감해질 수 있습니다. **부대 보안 규정에서 외부 API 사용·자료 저장 가능 여부를 먼저 확인**하세요.
- 군 일반망에서 Python 설치나 외부 API 접속이 막혀 있을 수 있습니다. 이 경우 정보체계 담당 부서와 협의가 필요합니다.
- AI가 만든 요약·평가는 반드시 출처 원문과 대조한 뒤 보고서에 씁니다.

## 7. 파일 구성

| 파일 | 내용 |
|---|---|
| `app.py` | 웹앱(화면 4개 + 보기 전용 링크 + 자동 수집 스케줄러) |
| `store.py` | 데이터 저장(SQLite) |
| `ai.py` | Claude API 호출(웹 검색), 출처 링크 확인 |
| `claude_collect.py` | Claude 앱이 수집한 소식을 검증해 저장(API 키 불필요) |
| `COLLECT_GUIDE.md` | 수집 절차·기준(예약 작업·수동 수집 공통) |
| `hwpx_export.py` | hwpx 파일 생성 |
| `assets/base_template.hwpx` | hwpx 서식 원본(검토보고서 양식) |
| `data/avionics.db` | **모든 데이터**(처음 실행 시 생성). 백업은 이 파일만 복사 |
| `config.json` | 설정·API 키(처음 실행 시 생성) |

## 8. 문제 해결

| 증상 | 해결 |
|---|---|
| `python`을 찾을 수 없음 | Python 재설치 시 "Add to PATH" 체크 |
| 5000번 포트 사용 중 | `config.json`의 `port`를 5050 등으로 변경 |
| 수집 실패: API 오류 404/400 | `model` 또는 `web_search_tool` 값을 콘솔 문서의 최신 값으로 변경 |
| 수집 실패: 401 | API 키 확인 |
| 다른 PC에서 링크가 안 열림 | `run_share.bat`으로 실행했는지, 방화벽 허용, 같은 네트워크인지 확인 |
| hwpx 모양 | 한글에서 열어 확인. 서식은 `assets/base_template.hwpx`의 문단 서식을 따릅니다 |
